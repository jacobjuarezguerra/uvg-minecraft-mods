# Campus UVG

[Descargar el mundo Campus UVG](Campus_UVG.zip)

El archivo incluye el mapa, las entidades y las paradas del recorrido. Las 29 paradas tienen descripciones en español y la partida tiene un icono UVG para reconocerla en el menú de mundos.

## Instalar

1. Cerrar Minecraft.
2. Instalar Minecraft Java 1.21.1, Java 21 y NeoForge 21.1.248 o superior.
3. Colocar University Guide 1.1.8 y Posted Signage 1.7.5 en la carpeta `mods` de esa instalación.
4. Descomprimir el ZIP. Copiar la carpeta `Campus_UVG`, que contiene `level.dat`, a la carpeta `saves` de Minecraft.
5. Abrir el juego y seleccionar la partida con el icono UVG. El nombre guardado del mundo es `world`.

Si utilizas un servidor, coloca el contenido de `Campus_UVG` en la carpeta de mundo configurada con el servidor detenido. El servidor y los jugadores deben tener los mismos mods.

## Recorrido

Haz clic derecho sobre el guía permanente para consultar los destinos. Elige una parada y síguelo hasta la llegada. El libro explica los controles y se puede recuperar con `/universityguide book`. Las descripciones identifican espacios como entrada, recepción, biblioteca, baños y accesos entre pisos.

Las descripciones se guardan tanto en los bloques de parada como en el índice de destinos. El archivo conserva las posiciones y los identificadores de las paradas.
